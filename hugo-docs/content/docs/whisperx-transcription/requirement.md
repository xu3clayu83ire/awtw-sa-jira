# 需求文件 — 會議錄音本機轉逐字稿

> 本文件模擬需求提出單位的視角撰寫，描述「要什麼」，不描述「怎麼做」。

## 需求背景與痛點

會議結束後常常需要花大量時間整理逐字稿或會議記錄，人工聽打慢、容易漏記，而且會議內容可能涉及敏感資訊，不希望把錄音上傳到雲端服務處理。

## 期望達成的目標

有一套工具，能把本機的會議錄音檔轉成逐字稿，並且標示出「誰在什麼時候說了什麼話」，全程在自己的電腦上執行，錄音檔不上傳到任何外部服務。

## 功能期望（業務角度）

1. 輸入一個錄音檔，或一整個資料夾的錄音檔，自動產出逐字稿。
2. 逐字稿能區分「誰說了什麼」（依語者分段標示）。
3. 全程在本機執行，音檔內容不外流。
4. 支援中文語音辨識，也能自動偵測其他語言。
5. 產出的逐字稿要有一份人類可直接閱讀的格式，也要有一份結構化資料，方便之後串接其他工具做會議摘要整理。

## 優先順序

| 優先度 | 項目 |
|---|---|
| Must | 錄音檔轉逐字稿（本機執行，不上雲） |
| Must | 支援中文辨識 |
| Should | 語者分離（標示「誰說了什麼」） |
| Should | 結構化資料輸出（供後續串接摘要工具） |
| Could | 依已知會議人數範圍，提高語者分離準確度 |

## 範圍邊界（不做的事）

- 不做即時（realtime）轉錄，只處理已錄好的音檔
- 不做會議摘要整理（逐字稿產出後的下一步，交給其他工具）
- 不做雲端上傳或雲端運算

## 驗收條件

| 情境 | 操作 | 預期結果 |
|---|---|---|
| 單一檔案轉錄 | 提供一個錄音檔 | 產生對應的逐字稿，內容與錄音相符 |
| 整批轉錄 | 提供一個裝有多個錄音檔的資料夾 | 每個錄音檔各自產生一份逐字稿 |
| 語者分離 | 提供多人對話的錄音，並完成語者分離所需設定 | 逐字稿依語者分段標示（例如「誰」在「幾分幾秒」說了什麼） |
| 不啟用語者分離 | 提供錄音，選擇跳過語者分離 | 仍正常產出逐字稿，不需額外設定 |
| 中文辨識 | 提供中文錄音 | 逐字稿正確辨識為中文內容 |
| 全程本機執行 | 執行轉錄過程中監看網路流量 | 沒有任何音檔資料被上傳到外部伺服器 |
